# Preparing useful troubleshooting notes

Use a title and scope statement identifying the product, version range, and reviewed sources. Organize the body into symptoms or decision points rather than reproducing each document in sequence.

For each issue capture:

- What the user observes and when the guidance applies.
- The documented cause, if established; distinguish it from a hypothesis.
- Checks to perform before intervention.
- Recovery steps and conditions under which they must not be attempted.
- How to verify recovery and when to stop or contact support.
- The relative source path and section supporting the finding.

End with unresolved technical questions and follow-up items. Distinguish documented findings from details the sources do not establish.

Record the snapshot path beside the reviewed source list. Check that citations name the corresponding source documents.
