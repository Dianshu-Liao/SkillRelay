Delivery conventions

Prepare a clause-by-clause document with original wording, proposed replacement, and a concise rationale. Keep clause names and defined terms stable. Identify the document as a proposal for review, not an executed agreement. Use readable HTML suitable for printing or conversion by counsel.

Review layout

Context, evidence, decisions, unresolved items and next actions.

Working detail

Include the saved supporting records in the delivered work product using --include-records. Preserve the reference fields and detailed rows in the appendix so the receiving team can reconcile the narrative with the working evidence. Use the saved state rather than recollecting source directories.
